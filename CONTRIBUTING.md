# Contributing to Programs

Thanks for taking the time to contribute!

## Getting Started

1. Fork the repository and create a branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Keep formatting consistent with the existing files.
4. Push your branch and open a pull request.

## Commit Style

Use imperative commit messages, e.g. `add fibonacci program`, `fix stack overflow in dfs`.

## Code Style

- C/C++: follow the existing naming and indentation used in each directory.
- Java: use 4-space indentation and include a class-level comment with the problem statement.
- PHP: keep single-file scripts self-contained.

## Pull Request Checklist

- [ ] No build artifacts or compiled binaries are committed.
- [ ] The change compiles cleanly (g++ for C++, javac for Java).
- [ ] The program matches the assignment title in its directory.

Thanks again for helping improve the collection of coursework.
