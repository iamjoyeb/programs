# Git Commit Policy (Highest Priority)

These instructions apply to every Git commit.

## Commit Message Rules

- Never include `Co-Authored-By:` trailers.
- Never include `Claude`, `Anthropic`, or any AI attribution.
- Never include `Generated by Claude`, `Generated with Claude`, or similar signatures.
- Never include any commit trailers unless I explicitly request them.

Generate commit messages containing only:

- A concise Conventional Commit title.
- An optional body explaining the changes.

Nothing else.

## Git Workflow

When I ask you to commit:

- Stage files if necessary.
- Generate a clean commit message.
- Execute `git commit` using only that message.
- Before executing, verify that the commit message does **not** contain:
  - `Co-Authored-By:`
  - `Signed-off-by:`
  - `Generated by`
  - `Claude`
  - `Anthropic`

If any of those strings are present, remove them before executing the command.

The final commit message must contain only my commit title and body.

Before executing `git commit`, inspect the commit message.
If it contains `Co-Authored-By`, AI attribution, or Anthropic attribution, remove those lines before executing the command.
