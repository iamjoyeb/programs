## Topics Covered

### Semester 3 — C++ & Data Structures (SY)

**Unit 1 — Classes and Objects** (47 programs)
* Class definition and member functions
* Object instantiation and basic I/O
* Practical domain models (Time, Date, Temperature, Book, Bank Account)
* Procedural fundamentals (conditionals, arithmetic)

**Unit 2 — Advanced Class Features** (76 programs)
* Default, Parameterized, Copy, and Overloaded Constructors
* Destructors and object lifecycle
* Friend functions and friend classes
* Inline functions
* Static data members and static member functions

**Unit 3 — Operator Overloading & Type Conversion** (55 programs)
* Basic-to-class conversion (conversion constructors)
* Class-to-basic conversion (conversion operators)
* Class-to-class explicit conversion
* Binary operator overloading (member function & friend function)
* Unary operator overloading

**Data Structures (C)** — (19 programs)
* **Unit 1**: Searching (Linear, Binary), Sorting (Bubble, Selection, Insertion, Merge), Sparse Matrix (7 programs)
* **Unit 2**: Singly, Doubly, Circular Singly, Circular Doubly Linked Lists (with full CRUD operations) (5 programs)
* **Unit 3**: Stacks (array & linked-list variants), Queues (linear array, circular array) (7 programs)

### Semester 4 — Advanced C++ & Data Structures (SY)

**Unit 1 — Inheritance** (56 programs)
* Single, Multiple, Multilevel, Hierarchical, Hybrid Inheritance
* Virtual Inheritance (diamond problem resolution)
* Abstract Classes with pure virtual functions
* Constructor chaining in derived classes
* Nested classes

**Unit 2 — Polymorphism** (49 programs)
* Compile-time: Function Overloading, Operator Overloading (binary & unary)
* Run-time: Virtual Functions, Pure Virtual Functions
* The `this` Pointer
* Base-to-derived pointer dispatch
* Virtual Destructors

**Unit 3 — File I/O, Streams & Formatting** (79 programs)
* File creation, reading, writing (`ifstream`, `ofstream`)
* Random Access files (`seekg`, `tellg`)
* Command-Line Arguments (`argc`, `argv`)
* Stream Formatting (`width`, `precision`, `fill`, `setf`, `unsetf`)
* I/O Manipulators (`iomanip`: `setw`, `setprecision`, `fixed`, `scientific`)
* `getline()` and basic stream operations
* File-based record management (student, employee, product)

**Advanced Data Structures (C)** — (30 programs)
* **Unit 1**: Graph representation (Adjacency Matrix), BFS & DFS traversal, dynamic vertex/edge input (7 programs)
* **Unit 2**: Binary Search Tree creation and display, Inorder/Preorder/Postorder traversals, all BST operations (3 programs)
* **Unit 3**: Fibonacci series, Square/Cube series, Number patterns, File I/O (11 programs)

### Semester 5 — Java, PHP & SQL (TY)

**Java** (118 programs)
* Basic I/O with `Scanner`
* Conditionals (`if-else`, `switch`), Loops (`for`, `while`, `break`, for-each)

## How to Compile and Run

### C Programs

```bash
gcc filename.c -o filename
./filename
```

### C++ Programs

```bash
g++ filename.cpp -o filename
./filename
```

### Java Programs

```bash
javac filename.java
java filename
```

### PHP Programs

CLI scripts:

```bash
php filename.php
```

Web/database programs (Unit-2 Assignment-3, Unit-3 Assignment-4) require a local server such as XAMPP:

1. Copy the program folder into `htdocs`.
2. Import the folder's `database.sql` into MySQL (e.g. via phpMyAdmin).
3. Adjust credentials in `db.php` if needed.
4. Open the folder URL in a browser (e.g. `http://localhost/<folder>/index.php`).
