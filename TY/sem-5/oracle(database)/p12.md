# Program 12: `sales` Table

## Create Table

```sql
CREATE TABLE sales (
    OrderID NUMBER(5),
    OrderDate DATE,
    OrderPrice NUMBER(10,2),
    OrderQuantity NUMBER(5),
    CustomerName VARCHAR2(30)
);
```

## Solve the Following Queries Using Aggregate Function

### 1. Count how many orders have made a customer with CustomerName of Smith.

```sql
SELECT COUNT(*) AS total_orders
FROM sales
WHERE CustomerName = 'Smith';
```

```text
TOTAL_ORDERS
------------
           3
```

### 2. Find number of unique customers that have ordered from the store.

```sql
SELECT COUNT(DISTINCT CustomerName) AS unique_customers
FROM sales;
```

```text
UNIQUE_CUSTOMERS
----------------
               4
```

### 3. Find out total no. of items ordered by all the customers.

```sql
SELECT SUM(OrderQuantity) AS total_items
FROM sales;
```

```text
TOTAL_ITEMS
-----------
         21
```

### 4. Find out average number of items per order.

```sql
SELECT AVG(OrderQuantity) AS average_items_per_order
FROM sales;
```

```text
AVERAGE_ITEMS_PER_ORDER
-----------------------
                      3
```

### 5. Find out the average OrderQuantity for all orders with OrderPrice greater than 200.

```sql
SELECT AVG(OrderQuantity) AS average_order_quantity
```

### 10. Find out the total amount of money spent for each of the customers.

```sql
SELECT CustomerName,
       SUM(OrderPrice * OrderQuantity) AS total_amount
FROM sales
GROUP BY CustomerName;
```

```text
CUSTOMERNAME                    TOTAL_AMOUNT
------------------------------ ------------
Baldwin                                6500
Johnson                                380
Smith                                  4440
Wood                                   4000
```

### 11. Select all unique customers, who have spent more than 1200 in the store.

```sql
SELECT CustomerName,
       SUM(OrderPrice * OrderQuantity) AS total_amount
FROM sales
GROUP BY CustomerName
HAVING SUM(OrderPrice * OrderQuantity) > 1200;
```

```text
CUSTOMERNAME                    TOTAL_AMOUNT
------------------------------ ------------
Baldwin                                6500
Smith                                  4440
Wood                                   4000
```

### 12. Select all customers that have ordered more than 5 items in total from all their orders.



### 13. Select all customers who have spent more than 1000, after 10/01/2005.

```sql
SELECT CustomerName,
       SUM(OrderPrice * OrderQuantity) AS total_amount
FROM sales
WHERE OrderDate > TO_DATE('10/01/2005','MM/DD/YYYY')
GROUP BY CustomerName
HAVING SUM(OrderPrice * OrderQuantity) > 1000;
```

