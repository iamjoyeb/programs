# Assignment 14: Salesmen, Item, and Sman_Item Tables

## Create Tables

```sql
CREATE TABLE SALESMEN (
    SID NUMBER(3) PRIMARY KEY,
    SNAME VARCHAR2(20),
    SADD VARCHAR2(30),
    SPHONE NUMBER(10)
);

CREATE TABLE ITEM (
    ITEMNO NUMBER(3) PRIMARY KEY,
    ITEMNAME VARCHAR2(20),
    PRICE NUMBER(10)
);

CREATE TABLE SMAN_ITEM (
    SID NUMBER(3) REFERENCES SALESMEN(SID),
    ITEMNO NUMBER(3) REFERENCES ITEM(ITEMNO),
    QTY NUMBER(5),
    PRIMARY KEY (SID, ITEMNO)
);
```

## 3. Salesmen with More Than 1000 Qty of Same Item

```sql
SELECT s.SNAME, i.ITEMNAME, si.QTY
FROM SALESMEN s JOIN SMAN_ITEM si ON s.SID=si.SID
JOIN ITEM i ON si.ITEMNO=i.ITEMNO
WHERE si.QTY > 1000;
```

## 4. Salesmen with Total Selling Amount

```sql
SELECT s.SNAME, SUM(si.QTY*i.PRICE) AS total_amount
FROM SALESMEN s JOIN SMAN_ITEM si ON s.SID=si.SID
JOIN ITEM i ON si.ITEMNO=i.ITEMNO
GROUP BY s.SNAME;
```

## 5. Item Wise Selling Details

```sql
SELECT i.ITEMNAME, s.SNAME, si.QTY, (si.QTY*i.PRICE) AS amount
FROM ITEM i JOIN SMAN_ITEM si ON i.ITEMNO=si.ITEMNO
JOIN SALESMEN s ON si.SID=s.SID
ORDER BY i.ITEMNAME;
```
