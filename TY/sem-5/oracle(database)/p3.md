## Create Table

```sql
CREATE TABLE Stud_Result (
    Stud_rollno NUMBER(3),
    Stud_name   VARCHAR2(15),
    City        VARCHAR2(20),
    Oracle      NUMBER(3),
    SE          NUMBER(3),
    ASP         NUMBER(3),
    Network     NUMBER(3)
);
```
