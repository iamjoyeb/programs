# Assignment 5: Customer Table with Constraints

## Create Table

```sql
CREATE TABLE Customer (
    cust_no NUMBER(5) PRIMARY KEY,
    Fname VARCHAR2(15),
    Lname VARCHAR2(15),
    birth_date DATE,
    city VARCHAR2(15),
    mob_no NUMBER(10),
    dept_name VARCHAR2(15),
    salary NUMBER(10) CHECK (salary >= 5000)
);
```
