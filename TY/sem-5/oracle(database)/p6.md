# Assignment 6: EMP Table

## Create Table

```sql
CREATE TABLE EMP (
    Emp_id NUMBER(6),
    Branch_id NUMBER(4),
    Fname VARCHAR2(15) NOT NULL,
    Lname VARCHAR2(15) NOT NULL,
    Dept VARCHAR2(15),
    Designation VARCHAR2(15),
    Salary NUMBER(10),
    Commission NUMBER(4)
);
```
