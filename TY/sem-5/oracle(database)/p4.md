# Assignment 4: Emp and Dept Tables

## Create Tables

```sql
CREATE TABLE Dept (
    dept_no NUMBER(3),
    dname VARCHAR2(20),
    location VARCHAR2(20)
);

CREATE TABLE Emp (
    emp_id NUMBER(5),
    name VARCHAR2(20),
    city VARCHAR2(20),
    job VARCHAR2(20),
    salary NUMBER(10),
    join_date DATE,
    commission NUMBER(10),
    dept_no NUMBER(3)
);
```
