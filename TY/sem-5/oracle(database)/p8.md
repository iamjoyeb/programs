# Assignment 8: Customer Table with Billing

## Create Table

```sql
CREATE TABLE Customer (
    Cust_Id NUMBER(4) PRIMARY KEY,
    Cust_city VARCHAR2(15),
    Product_Name VARCHAR2(20),
    Product_Price NUMBER(7,2) NOT NULL,
    Quantity NUMBER(5) NOT NULL,
    Bill_Amt NUMBER(10)
);
```
