# Assignment 11: ACCOUNT Table

## Create Table

```sql
CREATE TABLE ACCOUNT (
    ACC_NO NUMBER(5) PRIMARY KEY,
    NAME VARCHAR2(20) NOT NULL,
    DOB DATE,
    OPENING_DT DATE,
    AC_BALANCE NUMBER(10) CHECK (AC_BALANCE > 0),
    AC_TYPE VARCHAR2(1) CHECK (AC_TYPE IN ('S','C')),
    AC_STATUS VARCHAR2(1) CHECK (AC_STATUS IN ('O','C'))
);
```

## 6. String Functions on Name

```sql
SELECT NAME,
       SUBSTR(NAME,1,3) AS first_3,
       SUBSTR(NAME,-3) AS last_3,
       SUBSTR(NAME,5,1) AS fifth_char,
       INSTR(NAME,'M') AS pos_of_M,
       RPAD(NAME,10,'*') AS padded_name
FROM ACCOUNT;
```
