# Assignment 10: CLIENT_MASTER Table

## Create Table

```sql
CREATE TABLE CLIENT_MASTER (
    CLIENTNO NUMBER(4) PRIMARY KEY,
    NAME VARCHAR2(20) NOT NULL,
    ADDRESS VARCHAR2(30),
    CONNECTION_TYPE VARCHAR2(15) CHECK (CONNECTION_TYPE IN ('Domestic','Business','Temporary')),
    AREA VARCHAR2(10) CHECK (AREA IN ('Rural','Urban')),
    METER_ON_RENT VARCHAR2(1) CHECK (METER_ON_RENT IN ('y','n'))
);
```
