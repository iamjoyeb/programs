# Assignment 7: Student Table

## Create Table

```sql
CREATE TABLE Student (
    Stud_Id NUMBER(4) PRIMARY KEY,
    Stud_Name VARCHAR2(20) NOT NULL,
    Gender VARCHAR2(1) CHECK (Gender IN ('M','F')),
    Contact_No NUMBER(10),
    Sub1 NUMBER(3) CHECK (Sub1 BETWEEN 0 AND 100),
    Sub2 NUMBER(3) CHECK (Sub2 BETWEEN 0 AND 100),
    Sub3 NUMBER(3) CHECK (Sub3 BETWEEN 0 AND 100)
);
```

## 6. Total, Average, Min and Max Marks

```sql
SELECT SUM(Sub1+Sub2+Sub3) AS Total,
       AVG(Sub1+Sub2+Sub3)/3 AS Average,
       MIN(LEAST(Sub1,Sub2,Sub3)) AS Min_Mark,
       MAX(GREATEST(Sub1,Sub2,Sub3)) AS Max_Mark
FROM Student;
```
