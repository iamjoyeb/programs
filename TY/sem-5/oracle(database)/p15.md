# Program 15: Account Table

## Table Definition

| Field Name | Type | Size | Description |
|---|---|---:|---|
| Acc_no | NUMBER | 3 | Account Number - Primary key |
| Acc_name | CHARACTER | 30 | Account Holder Name |
| Acc_dob | DATE | — | Account Holder Birth Date |
| Acc_op_date | DATE | — | Account Opening Date |
| Acc_balance | NUMBER | 11,2 | Account Current Balance |
| Acc_type | CHARACTER | 1 | Account Type [Saving [S] / Current [C]] |
| Acc_status | CHARACTER | 1 | Account Status [Open [O] / Close [C]] |
| Acc_chk_flag | NUMBER | 1 | Account Check Book Flag [1-Yes, 0-No] |
| Acc_gender | CHARACTER | 1 | Account Holder Gender [F-Female, M-Male] |

## Create Table

```sql
CREATE TABLE Account (
    Acc_no NUMBER(3) PRIMARY KEY,
    Acc_name VARCHAR2(30),
    Acc_dob DATE,
    Acc_op_date DATE,
    Acc_balance NUMBER(11,2),
    Acc_type CHAR(1),
    Acc_status CHAR(1),
    Acc_chk_flag NUMBER(1),
    Acc_gender CHAR(1)
);
```

## 10. Display Information of Male Current Account Holder Whose Age Is Greater Than 25

```sql

WHERE Acc_gender = 'M'
  AND Acc_type = 'C'
```
